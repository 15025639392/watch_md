# 低电量与长时间徒步策略 v0.1

更新日期：2026-06-05

## 目标

Apple Watch 徒步 App 必须优先保证长时间户外会话的可靠性。

省电策略的核心不是简单减少功能，而是在电量压力下明确取舍：

1. 优先保留定位、偏航检测、轨迹本地保存和结束同步。
2. 可以降低地图刷新、实时同步、视觉效果和采样频率。
3. 不因为 iPhone 断连、底图失败或低电量丢失轨迹。

## 能力优先级

| 优先级 | 能力 | 低电量下策略 |
| --- | --- | --- |
| P0 | 本地轨迹保存 | 必须保留 |
| P0 | 定位与路线匹配 | 必须保留，可降低频率 |
| P0 | 偏航检测和提醒 | 必须保留，可降低重复提醒 |
| P0 | 会话结束和本地摘要 | 必须保留 |
| P1 | Watch 地图显示 | 保留，但降低刷新和细节 |
| P1 | 触觉提醒 | 保留关键提醒，减少重复提醒 |
| P1 | HealthKit 运动记录 | 尽量保留 |
| P2 | iPhone 实时状态同步 | 可降低频率或暂停 |
| P2 | 地图底图加载 | 可降级为路线线框 |
| P3 | 动效、细节 POI、非关键浮层 | 可关闭 |

## 电量模式

Watch 会话中定义 4 个运行模式。

| 模式 | 触发建议 | 产品目标 |
| --- | --- | --- |
| 标准模式 | 电量大于 35% | 地图体验和记录精度平衡 |
| 节能模式 | 电量 20-35% 或用户主动开启 | 降低刷新和同步，保持主要体验 |
| 低电量模式 | 电量 10-20% | 保留安全能力和轨迹，明显减少消耗 |
| 极低电量模式 | 电量小于 10% | 优先保存会话和关键定位 |

### 标准模式

适合普通 1-4 小时徒步。

策略：

1. 定位采样 3-5 秒。
2. 地图跟随当前位置，正常刷新。
3. 已走轨迹实时绘制。
4. 偏航检测每个可信定位点执行。
5. 会话状态 15-30 秒同步一次。
6. 轨迹可低频增量同步到 iPhone。

### 节能模式

适合较长徒步或电量开始有压力。

策略：

1. 定位采样调整为 5-10 秒。
2. 地图刷新频率降低。
3. 减少非关键动画。
4. 会话状态 30-60 秒同步一次。
5. 轨迹增量同步降低频率。
6. 保留转向提醒和偏航提醒。

### 低电量模式

适合电量不足但仍需要继续导航。

策略：

1. 定位采样调整为 10-20 秒，偏航中可临时提高频率。
2. 地图默认只在抬腕或状态变化时刷新。
3. 底图加载失败时直接使用路线线框。
4. 暂停 iPhone 实时状态同步，只保留结束后补传。
5. 关闭非关键 POI 和复杂浮层。
6. 偏航重复提醒间隔拉长。
7. 继续本地写入轨迹点和事件。

### 极低电量模式

适合即将没电，需要尽量保存最后状态。

策略：

1. 提示用户电量极低。
2. 保存当前会话摘要、最后位置和待同步状态。
3. 定位采样降到最低可接受频率。
4. 地图降级为路线线框和当前位置。
5. 停止实时同步。
6. 只保留偏航、回到路线、结束确认等关键提醒。
7. 尽快引导用户结束或保留会话。

## 用户主动省电

用户可以从地图页的低电量提示、长按快捷菜单或后续控制页开启“省电记录”。MVP 不要求完整控制页，只需要一个轻量入口。

适用场景：

1. 长线徒步。
2. 已知路线但仍想记录轨迹。
3. 电量不满但需要完成路线。

开启后：

1. 进入节能模式。
2. 顶部短暂显示“省电记录”。
3. 地图仍可查看。
4. 偏航提醒仍可用。

用户不应该被迫理解复杂技术设置。MVP 中只提供一个开关即可。

## 采样策略

### 定位采样

| 模式 | 正常采样 | 偏航中采样 | 暂停中采样 |
| --- | --- | --- | --- |
| 标准 | 3-5s | 3-5s | 30-60s |
| 节能 | 5-10s | 3-5s | 60s |
| 低电量 | 10-20s | 5-10s | 60-120s |
| 极低电量 | 20-60s | 10-20s | 120s |

### 轨迹写入

原则：

1. 写入本地比同步更重要。
2. 低电量时可以降低点密度，但不能完全停止。
3. 关键事件附近可以临时提高点密度。

关键事件包括：

1. 会话开始。
2. 偏航开始。
3. 回到路线。
4. 接近转向点。
5. 暂停和继续。
6. 会话结束。

## 地图省电策略

### 地图刷新

| 模式 | 地图策略 |
| --- | --- |
| 标准 | 跟随当前位置，正常刷新 |
| 节能 | 降低刷新频率，减少动画 |
| 低电量 | 抬腕或状态变化时刷新 |
| 极低电量 | 路线线框优先，底图可弱化 |

### 地图降级

当底图加载慢、网络弱或电量低时：

1. 保留计划路线。
2. 保留当前位置。
3. 保留已走轨迹。
4. 保留偏航连接线。
5. 弱化或隐藏地图 POI。
6. 不影响偏航检测。

用户感知上，它应该像“轻量地图模式”，不是错误状态。

## 同步省电策略

### 行进中

| 模式 | sessionStatus | trackChunk | eventChunk |
| --- | --- | --- | --- |
| 标准 | 15-30s | 可低频发送 | 及时发送 |
| 节能 | 30-60s | 降低频率 | 可延迟 |
| 低电量 | 状态变化才发 | 暂停实时发送 | 本地保存 |
| 极低电量 | 停止实时发送 | 本地保存 | 本地保存 |

### 结束后

结束同步仍然可靠优先：

1. Watch 先本地保存完整会话。
2. 电量允许时立即同步。
3. 电量太低时标记为待同步。
4. 下次充电、打开 App 或连接 iPhone 后补传。

## 提醒省电策略

触觉提醒不能完全关闭，因为它是户外安全核心。但低电量下要减少重复提醒。

| 事件 | 标准 | 节能 | 低电量 | 极低电量 |
| --- | --- | --- | --- | --- |
| 首次偏航 | 提醒 | 提醒 | 提醒 | 提醒 |
| 持续偏航 | 120s 限频 | 180s 限频 | 300s 限频 | 仅距离明显扩大 |
| 回到路线 | 提醒 | 提醒 | 可提醒 | 可提醒 |
| 转向点 | 提醒 | 提醒 | 提醒 | 只提醒明显转向 |
| 低电量 | 提醒 | 提醒 | 提醒 | 提醒 |
| 定位不稳 | 弱提醒或不提醒 | 不提醒 | 不提醒 | 不提醒 |

## 长时间徒步策略

长时间徒步指超过 4 小时的单次会话。

### 出发前提示

当路线预计耗时较长时，iPhone 和 Watch 应提示：

1. Watch 当前电量。
2. 是否建议开启省电记录。
3. 是否已同步路线。
4. 是否有定位和 HealthKit 权限。

### 行进中策略

1. 默认在会话超过 2 小时后建议开启省电记录。
2. 超过 4 小时后降低非关键同步频率。
3. 路线已经明显稳定时，减少地图动画。
4. 停留时间过长时，建议暂停而不是自动暂停。

### 数据分段

长会话本地存储应按时间或点数分段：

1. 轨迹点按 chunk 写入。
2. 事件单独写入。
3. 会话摘要定期更新。
4. App 恢复时从最近已保存 chunk 继续。

## App 恢复与崩溃保护

Watch 端必须定期落盘。

建议：

1. 每个轨迹点或小批量轨迹点写本地。
2. 每次状态变化立即写会话状态。
3. 每次事件发生立即写事件。
4. 每 1-5 分钟更新会话摘要草稿。
5. App 启动时检查是否存在 `active` 或 `paused` 会话。

恢复后：

1. 生成 `appRecovered` 事件。
2. 继续原会话。
3. 不重复创建 session。
4. 不丢弃未同步 chunk。

## UI 规则

### Watch 顶部状态

低电量提醒不要长期霸占地图状态。

优先级建议：

1. 偏航。
2. 接近转向点。
3. 定位不稳。
4. 低电量。
5. 已暂停。
6. 路线上。

低电量出现时：

1. 短暂显示电量提醒。
2. 然后回到路线状态。
3. 电量图标或小标识可保留。

### 省电模式提示

文案要短：

1. “省电记录已开启”
2. “电量 18%，降低刷新”
3. “电量低，轨迹仍在记录”
4. “待连接 iPhone 后同步”

### iPhone 显示

iPhone 可以显示：

1. Watch 电量。
2. 当前运行模式。
3. 最近同步时间。
4. 轨迹是否已完整保存。

## 事件记录

MVP 只要求将低电量写入 `SessionEvent.lowBattery`。模式变化事件作为后续能力。

### batteryModeChanged

建议后续加入事件类型。

payload：

```json
{
  "fromMode": "standard",
  "toMode": "lowPower",
  "batteryPercent": 18,
  "reason": "batteryThreshold"
}
```

### lowBattery

payload：

```json
{
  "batteryPercent": 18,
  "mode": "lowPower",
  "locationSamplingSeconds": 15,
  "syncPaused": true
}
```

## MVP 策略

第一版可以先实现：

1. 标准模式。
2. 低电量模式。
3. 用户主动省电轻量入口。
4. 电量低于 20% 时降低地图刷新和同步频率。
5. 电量低于 10% 时停止实时同步，只保留本地保存。
6. 地图底图失败时显示路线线框。
7. 定期本地保存会话状态。

暂缓：

1. 复杂自动模式切换 UI。
2. 精细化采样算法。
3. 多日徒步模式。
4. 太阳高度、天气、温度对续航的预测。

## 验收标准

1. 低电量时轨迹仍会本地保存。
2. 低电量时偏航提醒仍可触发。
3. 低电量时 iPhone 实时同步可以暂停，但结束后可补传。
4. App 重启后能恢复进行中的会话。
5. 地图底图不可用时，路线线框仍可显示。
6. 用户能通过轻量入口主动开启省电记录。
7. Watch 顶部状态不会被低电量提示长期占用。
8. 低电量策略不会导致结束流程失败。

## 待实测问题

1. Apple Watch 不同机型在地图 + GPS + HealthKit 下的实际耗电。
2. 3-5 秒采样和 10-20 秒采样对轨迹质量的影响。
3. 低电量下 WatchConnectivity 补传的可靠性。
4. Workout session 后台运行对地图刷新和同步的影响。
5. 常亮屏幕对徒步地图页的续航影响。
