# 华为 WATCH GT 系列徒步 App MVP 规格 v0.1

更新日期：2026-06-06  
适用范围：Apple Watch MVP 之后的华为 WATCH GT 系列验证线，优先面向 `HUAWEI WATCH GT 6` / `HUAWEI WATCH GT 5`。本文不改变当前首发 Apple Watch / watchOS 的 MVP 范围。

## 产品定位

华为 WATCH GT 系列 MVP 的目标不是先做完整腕上地图 App，而是验证“长续航轻量导航协同”是否能形成徒步闭环。

一句话定义：

> 手机负责路线准备、地图预览、复杂导航和复盘；GT 系列优先负责关键路线状态、偏航提醒、关键点提醒、轻量轨迹或运动状态回传。

GT 系列用户价值在长续航和运动健康场景。首轮规格应避免承诺复杂 GPX 渲染、完整离线地图、全天后台第三方定位或所有 GT 型号一致体验。

## 核心用户场景

### 出发前

用户在华为手机或 Android 手机上选择远端路线或导入 GPX，手机生成 GT 可用的轻量路线 payload，包括路线摘要、关键点、偏航阈值、下一段方向提示和必要的简化几何。

### 行进中

手机保持路线主计算和复杂地图能力。GT 显示简化导航状态，例如当前路线名、行进状态、距离、时长、下一个关键点、偏航状态、定位/连接状态和电量提醒。

如果目标 GT 机型验证支持足够的轻量绘制和定位能力，可以逐步增加简化路线线条、当前位置点和已走轨迹；否则 GT MVP 退化为“手机导航 + 手表提醒 + 会话控制”的协同模式。

### 风险发生时

GT 通过震动或通知提醒用户偏航、接近关键点、手机连接中断、定位不稳或电量不足。复杂地图判断由手机侧负责，GT 只展示结果和必要操作。

### 结束后

用户可在 GT 或手机上结束会话。手机汇总实际轨迹、摘要和事件。如果 GT 不能稳定独立记录轨迹，则以手机轨迹为准，GT 只回传控制事件和可获得的运动状态。

## 端分工

| 端 | 产品职责 | 不承担 |
| --- | --- | --- |
| 华为 / Android 手机 | 路线列表、GPX 导入、路线详情、地图预览、路线匹配、偏航计算、轨迹主记录、复盘、设置 | 只作为通知转发器 |
| WATCH GT 系列 | 轻量导航状态、偏航震动、关键点提醒、开始/暂停/继续/结束入口、连接和电量状态 | 完整地图研究、复杂 GPX 渲染、独立路线编辑、深度复盘 |
| 服务端 | 路线目录、路线详情、版本校验 | 直接控制 GT 会话 |

## MVP 功能范围

GT 系列第一版以“协同闭环”为 P0：

1. 手机从远端接口获取路线列表，并支持导入 GPX。
2. 手机展示计划路线和路线详情。
3. 手机生成 GT 轻量路线 payload。
4. 手机通过 Wear Engine 或已验证通信链路向 GT 下发路线摘要、关键点、状态和提醒配置。
5. GT 收到路线后回传 ACK，并要求用户确认“使用此路线开始”。
6. 用户可在 GT 上开始、暂停、继续、结束会话。
7. 手机侧负责主轨迹记录和偏航计算，GT 展示偏航状态并震动提醒。
8. GT 展示下一个关键点或转向提示。
9. 手机与 GT 断连时，GT 显示连接异常；能否继续独立记录由真机验证决定。
10. 结束后手机生成复盘，记录 GT 控制事件和提醒事件。
11. 如果目标 GT 真机支持轻量轨迹记录，则 GT 可补充回传轨迹点；否则不作为 P0。
12. 无计划路线时允许自由记录或自由运动状态展示；是否由 GT 独立记录轨迹需要实测。

## GT 端页面结构

GT 首轮页面应比 WATCH 数字系列更轻。

| 页面 | 目标 | MVP 内容 |
| --- | --- | --- |
| 状态页 | 抬腕确认是否正常行进 | 路线名、当前状态、距离、时长、偏航状态、连接状态 |
| 提醒页 | 展示下一步判断 | 下一个关键点、剩余距离、转向方向、偏航距离 |
| 控制页 | 执行低频操作 | 开始、暂停、继续、结束、二次确认 |
| 简化路线页 | 可选验证 | 简化路线线条、当前位置、已走轨迹；仅在目标机型能力允许时启用 |

## 技术假设

| 能力 | 首选验证路径 | 状态 |
| --- | --- | --- |
| 手表端应用 | `liteWearable` 或目标 GT 支持的轻量穿戴开发范式 | 需要 GT 6 / 5 真机验证 |
| 手机-手表同步 | Wear Engine 消息 / 文件 / 通知能力 | 需要验证地区、手机系统和后台稳定性 |
| 路线格式 | 轻量 JSON payload | P0 |
| 偏航计算 | 手机侧计算，GT 展示结果 | P0 |
| 轨迹记录 | 手机侧为主，GT 独立记录后置 | P0/P1 |
| 提醒 | GT 震动 / 通知 / 状态页 | 需要 API 和权限验证 |
| 健康数据 | 华为 Health Kit / Health Service Kit 后置 | 不作为 P0 |
| 分发 | AppGallery Connect / 手表应用市场 / 协同应用路径 | 需要验证 |

## 轻量路线 payload

GT 不应默认接收完整原始 GPX。首轮建议下发更小的 `GtNavigationPayload`。

| 字段 | 说明 |
| --- | --- |
| `routeId` | 路线稳定 ID |
| `routeVersion` | 路线版本 |
| `routeName` | 路线名称 |
| `distanceMeters` | 计划距离 |
| `ascentMeters` | 计划爬升，可为空 |
| `estimatedDurationSeconds` | 预计耗时，可为空 |
| `startName` / `endName` | 起终点名称 |
| `waypoints` | 起终点和关键提醒点 |
| `turnPrompts` | 手机侧预生成的转向或关键方向提示 |
| `offRouteThresholdMeters` | 偏航阈值 |
| `checksum` | 内容校验 |
| `expiresAt` | 可选，避免旧路线长期误用 |

如果真机验证支持简化几何，可增加：

| 字段 | 说明 |
| --- | --- |
| `simplifiedPolyline` | 低点数路线线条 |
| `bounds` | 路线包围盒 |
| `samplingHintMeters` | 手机或 GT 采样建议 |

## 状态同步

GT 与手机之间至少同步以下状态：

| 方向 | 对象 | 说明 |
| --- | --- | --- |
| 手机 -> GT | `routeInstalled` | 路线已安装或更新 |
| 手机 -> GT | `navigationStatus` | 路线上、疑似偏航、已偏航、定位不稳、暂停 |
| 手机 -> GT | `nextPrompt` | 下一个关键点或转向提醒 |
| 手机 -> GT | `sessionMetrics` | 距离、时长、速度、剩余距离 |
| GT -> 手机 | `routeAck` | 路线接收、校验和安装结果 |
| GT -> 手机 | `controlEvent` | 开始、暂停、继续、结束 |
| GT -> 手机 | `deviceStatus` | 电量、佩戴、连接、充电状态 |
| GT -> 手机 | `trackPoints` | 可选，只有独立定位验证通过后启用 |

## 第一版暂不做

1. 支持所有 WATCH GT 型号。
2. 把 GT 系列写成完整智能手表 App。
3. GT 独立 GPX 导入和路线编辑。
4. GT 完整地图底图、离线地图和多地图源。
5. GT 脱离手机完成完整路线导航和复盘。
6. iPhone 与 GT 深度联动主路径。
7. 路线社区、附近路线发现、AI 推荐。
8. 复杂安全判断，例如日落风险、天气风险和自动返航。
9. 写入华为健康运动记录作为 P0。
10. AppGallery 正式上架承诺。

## 验证通过标准

| 阶段 | 标准 |
| --- | --- |
| H-GT-0 环境 | DevEco Studio 可创建或导入 GT 目标轻量工程 |
| H-GT-1 安装 | GT 6 / 5 真机可安装或接入协同 Demo |
| H-GT-2 路线下发 | 手机下发轻量 payload，GT 回 ACK |
| H-GT-3 状态展示 | GT 可展示路线名、距离、时长、连接和偏航状态 |
| H-GT-4 提醒 | 偏航和关键点提醒能触发可感知震动 |
| H-GT-5 控制 | GT 开始、暂停、继续、结束事件可回到手机 |
| H-GT-6 复盘 | 手机可生成一次含 GT 控制事件的复盘 |
| H-GT-7 独立能力 | 可选验证 GT 独立定位、简化路线绘制和断连后行为 |

## 与 WatchOS MVP 的关系

| 项 | WatchOS MVP | 华为 GT 系列 MVP |
| --- | --- | --- |
| 首发状态 | 当前主线 | Apple Watch MVP 之后验证 |
| 手表角色 | 主导航端 | 轻量协同端，能力通过真机逐步上探 |
| 手机角色 | 准备和复盘 | 准备、主计算、主地图、复盘 |
| 同步 | WatchConnectivity | Wear Engine 或已验证链路 |
| 地图 | Watch 端地图页核心 | GT 端不承诺完整地图，先做状态和提醒 |
| 偏航计算 | Watch 端本地计算 | 手机侧优先计算，GT 展示和提醒 |
| 轨迹记录 | Watch 端主记录 | 手机侧主记录，GT 独立记录后置 |

## 后续定义顺序

1. GT 轻量 payload 与 ACK 字段。
2. GT 状态页和提醒页线框。
3. 手机侧偏航结果同步协议。
4. GT 断连、低电量和后台提醒测试 checklist。
5. GT 独立定位和简化路线绘制专项验证。
6. GT 与 WATCH 数字系列共用模型边界整理。
