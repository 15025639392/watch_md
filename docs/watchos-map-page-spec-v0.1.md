# WatchOS 徒步地图页规格 v0.1

更新日期：2026-06-05

## 设计目标

Watch 地图页是徒步过程中的默认首页。它的目标不是复刻 iPhone 地图，而是让用户抬腕 2 秒内完成判断：

1. 我在计划路线上吗。
2. 下一段路线往哪里走。
3. 我离下一个转向点或关键点还有多远。
4. 当前是否需要处理风险。

地图页要始终优先服务路线判断。距离、时长、心率等数据可以出现，但不能抢主视图。

## 默认线框

地图页由 5 层组成：

| 层级 | 内容 | 说明 |
| --- | --- | --- |
| 底层 | Apple 地图底图 | 降低视觉干扰，优先让路线清楚 |
| 路线层 | 计划路线、已走轨迹、起点、终点、关键点 | 计划路线比已走轨迹更醒目 |
| 定位层 | 当前定位点、方向箭头、定位精度圈 | 当前点必须是最清楚的元素 |
| 状态层 | 顶部状态胶囊、底部下一步提示 | 只放当前最重要的一条判断 |
| 操作层 | 长按菜单、暂停/结束确认 | 默认隐藏，只在用户主动操作时出现 |

### 屏幕结构

```txt
┌────────────────────┐
│  状态胶囊           │
│                    │
│       地图          │
│   计划路线/轨迹      │
│       当前点         │
│                    │
│  下一步提示          │
└────────────────────┘
```

### 顶部状态胶囊

顶部只显示当前最关键状态，最多一行：

| 状态 | 示例文案 |
| --- | --- |
| 正常行进 | 路线上 |
| 接近转向点 | 前方 45m 左转 |
| 偏航 | 偏离 38m |
| 定位弱 | 定位不稳 |
| 暂停 | 已暂停 |
| 电量风险 | 电量 12% |

### 底部下一步提示

底部显示下一步行动或路线关系，最多两段信息：

| 场景 | 示例 |
| --- | --- |
| 正常行进 | 剩余 2.4km |
| 接近转向点 | 继续 45m 后左转 |
| 偏航 | 向西南回到路线 |
| 接近终点 | 终点 120m |
| 已暂停 | 记录暂停中 |

## 地图元素样式

| 元素 | 视觉建议 | 优先级 |
| --- | --- | --- |
| 当前定位点 | 高对比圆点 + 方向箭头 | 最高 |
| 计划路线 | 明亮主色、粗线 | 高 |
| 下一段路线 | 比计划路线更亮或带轻微高亮 | 高 |
| 已走轨迹 | 较细、半透明 | 中 |
| 偏航连接线 | 警示色虚线，连接当前位置和最近路线点 | 高，仅偏航时显示 |
| 起点/终点 | 简洁图标或小圆点 | 中 |
| 关键点 | 小标记，接近时放大或高亮 | 中 |
| 定位精度圈 | 半透明圆形 | 低，仅定位不稳时明显 |
| 地图 POI | 默认弱化 | 低 |

## 主要状态

地图页至少需要覆盖 8 个状态。

### 1. 未开始

用户已同步路线到 Watch，但还没有开始记录。

显示：

1. 路线全览。
2. 起点、终点。
3. 当前定位点。
4. 路线名称或距离。
5. 开始按钮。

交互：

1. 点击开始进入记录。
2. Digital Crown 缩放路线。
3. 长按可删除本地路线或返回路线列表。

### 2. 正常行进

用户在计划路线附近行进，定位正常。

显示：

1. 地图自动居中当前定位点。
2. 计划路线和已走轨迹。
3. 顶部显示“路线上”。
4. 底部显示剩余距离或下一个关键点。

触发条件：

1. 当前位置到计划路线的距离小于偏航阈值。
2. 定位精度满足记录要求。
3. 当前未暂停。

### 3. 接近转向点

用户即将到达路线几何上的明显转向点。

显示：

1. 高亮下一段路线。
2. 顶部显示“前方 Xm 左转/右转/急转”。
3. 底部显示“继续 Xm 后转向”。
4. 地图缩放可略微放大转向区域。

触发条件：

1. 当前位置沿计划路线投影后，前方最近转向点距离小于提醒阈值。
2. 该转向点尚未提醒过，或用户离开后再次接近。
3. 用户没有处于偏航状态。

首版判断方式：

1. 从 GPX 点序列中计算连续路段方向角。
2. 当前后方向变化超过 35-45 度时生成转向点。
3. 距离太近的转向点合并。
4. 徒步中按当前位置在线路上的投影距离判断是否接近。

### 4. 偏航

用户明显离开计划路线。

显示：

1. 顶部显示“偏离 Xm”。
2. 当前点和计划路线之间显示警示色连接线。
3. 最近可回到路线的位置高亮。
4. 底部显示回到路线的大致方向，例如“向西南回到路线”。

触觉：

1. 首次进入偏航状态时震动。
2. 偏航距离持续扩大时可再次提醒，但必须限频。

触发条件：

1. 当前位置到计划路线的最近距离超过偏航阈值。
2. 连续多个定位点都满足偏航条件，避免 GPS 漂移误报。

退出条件：

1. 当前位置回到路线阈值内。
2. 或用户主动选择“继续当前路径”，进入临时忽略偏航。

### 5. 定位不稳

GPS 精度不足，不能可靠判断偏航。

显示：

1. 顶部显示“定位不稳”。
2. 当前点周围显示更明显的精度圈。
3. 暂时弱化偏航判断。

触发条件：

1. 定位水平精度超过设定阈值。
2. 或连续定位更新中断超过设定时间。

产品原则：

1. 定位不稳时不要频繁报偏航。
2. 要让用户知道当前判断可信度降低。

### 6. 暂停中

用户主动暂停记录，或系统进入暂停状态。

显示：

1. 顶部显示“已暂停”。
2. 地图仍可查看。
3. 底部显示“记录暂停中”。
4. 操作层提供继续和结束。

数据处理：

1. 暂停中不写入正式轨迹点。
2. 仍可低频更新当前位置用于地图查看。

### 7. 接近终点

用户接近路线终点。

显示：

1. 终点高亮。
2. 顶部显示“终点 Xm”。
3. 底部显示剩余距离。

交互：

1. 到达终点后提示是否结束。
2. 不自动结束，避免用户绕行或继续探索。

### 8. 低电量

手表电量不足以支撑当前地图和定位强度。

显示：

1. 顶部短暂显示“电量 X%”。
2. 可弹出省电建议。

建议操作：

1. 降低地图刷新频率。
2. 降低轨迹点采样频率。
3. 保留偏航检测和轨迹记录。
4. 允许关闭常亮地图。

## 触觉提醒规则

| 事件 | 提醒强度 | 限频 |
| --- | --- | --- |
| 接近转向点 | 轻震一次 | 同一转向点只提醒一次 |
| 偏航 | 明显震动 | 进入偏航时提醒，持续偏航限频提醒 |
| 回到路线 | 轻震一次 | 每次偏航恢复提醒一次 |
| 接近终点 | 轻震一次 | 同一路线只提醒一次 |
| 低电量 | 明显震动 | 按电量阈值提醒 |
| 定位不稳 | 轻震或不震 | 避免频繁打扰 |

## 操作设计

### Digital Crown

默认控制地图缩放。

规则：

1. 用户转动表冠后进入手动缩放状态。
2. 一段时间无操作后回到自动缩放。
3. 偏航或接近转向点时，系统可以临时调整缩放级别。

### 单击地图

切换信息浮层密度：

1. 极简：只显示路线和当前点。
2. 标准：显示状态胶囊和下一步提示。
3. 数据：叠加距离、时长、海拔中的 1-2 个指标。

### 长按地图

打开快捷菜单：

1. 暂停/继续。
2. 标记点。
3. 返航。
4. 结束。

## 关键阈值建议

这些值用于 MVP 验证，后续需要实测调参。

| 项 | 建议默认值 | 说明 |
| --- | --- | --- |
| 偏航阈值 | 30m | 山区 GPS 漂移较大，不能过窄 |
| 回到路线阈值 | 20m | 小于偏航阈值，避免状态来回跳 |
| 转向点角度阈值 | 40 度 | 小弯不提醒，明显转向才提醒 |
| 转向点合并距离 | 30m | 避免连续小折线反复提醒 |
| 转向提醒距离 | 50m | 徒步场景适合提前提醒 |
| 定位弱精度阈值 | 50m | 超过后降低偏航判断可信度 |
| 轨迹采样间隔 | 3-5s | 平衡轨迹精度和续航 |
| 偏航确认点数 | 3 个定位点 | 降低误报 |

## 空状态和异常状态

| 状态 | 显示 | 处理 |
| --- | --- | --- |
| 没有路线 | 显示当前位置地图和“从 iPhone 同步路线” | 引导回 iPhone |
| 路线同步中 | 显示进度和最近路线名称 | 禁止开始 |
| 路线同步失败 | 显示失败原因和重试 | 保留旧路线 |
| 定位权限缺失 | 显示开启定位提示 | 引导在 iPhone/Watch 设置授权 |
| HealthKit 权限缺失 | 可开始地图导航，但运动数据受限 | 引导授权 |
| 地图加载失败 | 显示路线线框和当前位置 | 不影响轨迹记录 |
| Watch 与 iPhone 断连 | Watch 继续独立记录 | 结束后再同步 |

## MVP 验收标准

1. 用户开始徒步后，Watch 首屏进入地图页。
2. 地图能同时显示计划路线、已走轨迹和当前位置。
3. 正常行进时，用户抬腕可判断自己在路线上的位置。
4. 接近明显转向点时，Watch 能提前提醒并高亮下一段路线。
5. 偏离路线超过阈值后，Watch 能震动提醒并显示偏航距离。
6. GPS 精度差时，App 不应频繁误报偏航。
7. 暂停、继续、结束不会丢失已记录轨迹。
8. 地图底图加载失败时，路线线框和轨迹记录仍可继续。
